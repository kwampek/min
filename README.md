| ---------------------------- | ----------- | ---------------------------- |

# MIN Messenger - Backend

## Физическая модель

Физическая модель включает следующие таблицы:


`Users` (Пользователи) — хранит информацию о пользователях, включая их логин, пароль, аватар и настройки приватности.

`Chats` (Чаты) — содержит данные о чатах, включая их тип, название и описание.

`ChatMembers` (Участники чатов) — связывает пользователей с чатами и хранит информацию о роли пользователя в чате.

`Messages` (Сообщения) — хранит текст сообщений и информацию о прикрепленных медиафайлах.

`Call` (Звонки) — содержит данные о звонках, включая время начала и окончания.

`CallMembers` (Участники звонка) — связывает пользователей со звонками.

`MediaFiles` (Медиафайлы) — хранит информацию о загруженных файлах.

`Folders` (Папки) - хранит необходимую информацию о папках.

`FolderChats` (Чаты из папки) - хранит все чаты и папки.

`Tokens` - Хранит токены для поддержки jwt.


## Сценарии

1) При регистрации пользователь добавляется в таблицу `Users`.
2) Любой пользователь может создать свой собственный чат, информация о котором добавляется в таблицу `Chats`.
3) Любой пользователь может найти чат в глобальном поиске. После присоединения к чату создается объект `ChatMembers`.
4) Для упрощения доступа к чатам используются папки. При создании папки обновляется таблица `Folders`. При дальнейшем добавлении чатов в папку будет добавляться запись в `FolderChats`.
5) Каждое написанное текстовое сообщение добавляется в таблицу `Messages`. Если при этом сообщение содержит медиафайлы, они сохраняются локально и добавляются в таблицу `MediaFiles`.
